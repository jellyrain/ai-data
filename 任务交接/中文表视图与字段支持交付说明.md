# 中文表、视图与字段支持交付说明

日期：2026-10-09。

用户要求允许中文表名和视图名称。截图中的 `items.43.columns.*.name` 错误来自字段名校验，因此本轮同时贯通中文列名。主代理单独实施，依赖操作、数据库迁移均为 0。

## 主要改动

此前发现结果中的列名只接受英文字母、数字和下划线；一个中文列就会使整个发现响应校验失败。白名单对象、业务目录、权限、查询 DSL 和 SQL 编译也有同类限制。

现在对应规则允许汉字，包括简体、繁体，以及原有英文字母、数字和下划线；目录及字段引用沿用点号分段。支持中文 schema、表名、视图名、列名、查询别名和结果列名。查询结果用于报表、指标、字段脱敏及偏好时，相关合同同步接受中文引用。

名称仍通过字符规则与对象白名单校验。物理名称由 DAS 目录映射提供，SQL 编译逐段引用标识符，条件值继续作为参数传递。分号、引号、SQL 注释等任意表达式没有放开。


普通测试合计 1,657 项。新增验证包括：

- 中文表、视图、列的发现响应、白名单选择、目录及查询合同。
- 中文 schema 下创建真实表与视图，经发现、白名单保存回读、公共目录、查询规划与连接器执行，得到预期中文列和值；取消视图白名单后查询被拒绝。
- 中文对象仍执行对象权限、列拒绝、行过滤及脱敏；未经授权的查询不会签名。
- SQL Server、MySQL、PostgreSQL、Oracle 四种方言正确引用中文名称；含 SQL 片段的条件值保持参数绑定，篡改物理对象名仍被拒绝。
- 中文字段可用于指标日期依据、去重键、维度、预聚合与报表保存。
- 浏览器可发现中文对象、勾选保存、重新读取及取消，同时回归数据库下拉、删除与窄屏布局。

SQL Server 实机验证使用自动创建并清理的隔离库，未修改用户业务库。其余三种数据库完成编译器测试，未做实机验证；真实模型问答未在本轮运行。
