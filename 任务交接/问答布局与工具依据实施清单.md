# 问答布局与工具依据实施清单

日期：2026-10-08。用户审核两张效果稿后回复“差不多 来吧”，批准主代理单独实施。

## 目的与范围

1. 回答正文保留主要结论与 Markdown 表格；原始结果放入默认收起的“查询数据”，多个结果用标签切换。
2. 表格标题与行数在左，展示方式、显示列、导出本表、保存为报表集中在右。表格按内容计算高度，大结果滚动，分页按需要显示。
3. 工具调用使用紧凑的图标和状态文案；点击后在分析依据查看该次调用的输入、结果、状态、耗时、错误及关联查询 SQL。
4. 适配手机抽屉、浅色与深色；保留流式显示、过程折叠、历史恢复、会话删除及报表隔离。

## 文件与依赖

- 修改 Web 分析页、运行面板、依据面板、结果表格、Markdown 渲染及对应样式。
- 新增查询结果面板和必要的展示模型；更新 Web 单元与浏览器测试及隔离验收夹具。
- 在本目录保存交付说明、流程图和静态验收截图，README 追加索引。
- 复用现有 API 与合同；依赖安装、升级和卸载为 0。

## 场景与验证

| 前提与操作                       | 验收预期                                             |
| -------------------------------- | ---------------------------------------------------- |
| 一轮回答产生多个查询结果         | 正文可读，原始结果默认收起，展开只显示当前选中结果   |
| SSE 样本与完整证据对应同一结果   | 按证据 ID 合并，完整结果替换样本，顺序与选择保持稳定 |
| 切换单行、空结果与大结果         | 高度适配，单页结果不显示分页，大结果可翻页与滚动     |
| 同名工具失败后重试，点击各次调用 | 右侧分别显示正确详情，失败状态和原因保留             |
| 读取工具详情、切换查询依据       | 按明确的证据引用定位 SQL；未知关联不猜测             |
| 导出和保存当前表                 | 仅处理所选证据，导出包含该证据完整已保存结果         |
| 流式生成、完成、刷新和取消       | 正文、过程和状态保持一致；完成后原始结果仍默认收起   |
| 手机点击工具或表格操作           | 抽屉可用，按钮换行，不造成页面横向溢出               |
