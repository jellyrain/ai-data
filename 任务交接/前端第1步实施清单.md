## 交互与验收场景

| 场景                                 | 预期结果                                                              |
| ------------------------------------ | --------------------------------------------------------------------- |
| 打开原型、切换三个核心页面           | 导航、标题和当前页状态一致，可直接访问对应哈希路由                    |
| 新会话、提交问题、回答澄清、查看结果 | 输入得到保留，流程状态可追踪，结果、图表与证据使用一致的虚构数据      |
| 运行中取消、失败、空结果             | 可检查三种不同结果状态，取消后演示定时回调不覆盖终态                  |
| 表格翻页及页大小变化                 | 行数与当前页范围一致，页码保持有效                                    |
| 修改报表参数后执行、切换历史         | 当前参数与已展示结果分别标记，历史保留原参数、定义版本和执行标识      |
| 进入三种编辑方式、模拟保存、分享     | 共用同一编辑草稿与定义基准；保存和分享推进定义版本，保留所选结果      |
| 导出流程演示                         | 格式、所选结果、生成中及成功/失败状态可检查，页面明确模拟范围         |
| Agent/模型详情、新版本与启停         | 版本可读取，表单有校验，保存失败保留输入，既有会话标明固定 Agent 版本 |
| 工具与 Skill 选择                    | 绑定 Skill 时校验 `read_skill_reference`，凭据原文不进入公开详情      |
| 桌面、窄屏、长字段、键盘与焦点       | 主操作可达；表格在自身区域横向滚动；弹窗可关闭，焦点可见              |
