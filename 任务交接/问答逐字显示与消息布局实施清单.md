# 问答逐字显示与消息布局实施清单

日期：2026-10-08

用户希望 AI 回复呈现逐字输出效果；在前端实施清单后补充“自己输入的内容放到右边”，本轮按这两个目标实施。

## 目的与范围

- AI 流式文字按字符逐步显示，积压较多时自动加速追赶；消息完成、停止及历史恢复时立即显示当前完整正文。
- 用户消息使用靠右气泡，AI 回复沿用左侧布局，桌面与手机均支持长文本换行。
- 沿用现有 Markdown、代码、表格、主题及无障碍设置。系统偏好减少动态效果时直接显示收到的文字。

## 文件与依赖

- 新增 `apps/web/src/shared/content/use-streaming-text.ts`，管理逐字显示与清理。
- 修改 `apps/web/src/shared/content/markdown-content.vue`，接入逐字显示。
- 修改 `apps/web/src/styles/analysis.css`，调整用户消息对齐和宽度。
- 新增对应单元测试与 `apps/web/tests/e2e/analysis-presentation.spec.ts`。
- 完成后新增交付与流程图，追加任务交接 README。

主代理单独实施，依赖操作为 0。本轮为前端展示调整，后端沿用已完成的流式性能修复。

## 验证

- 单元测试覆盖逐字递增、持续输入与大段追赶、完整字符、停止、历史、减少动态效果和卸载清理。
- 浏览器检查真实 HTTP 夹具的流式文字、停止与恢复、桌面/手机消息对齐及长文本换行。
- 执行 Web 类型检查、修改文件 lint/格式及生产构建。
