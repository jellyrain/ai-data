- 采用中性色表面、细分隔线、清楚的文字层级和紧凑操作。
- 紫色用于当前选择与主要操作，作为现有配色选项的示例。
- 报表中心使用卡片，详情以单张图表为主体，筛选定义用列表与属性面板组织。
- 使用项目已有导航名称，沿用中文系统字体的方向。
