# 前端第 7 步行为与兼容性场景

承接已批准的[实施清单](../前端第7步实施清单.md)。依赖安装后先验证固定库与字体组合，再按场景落实业务测试和实现。

## 依赖兼容性前置验证

| 前提与操作                                              | 预期                                                                                                                   |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 用户完成六项 Web 依赖安装                               | 实际包版本、许可及锁文件与核对记录一致；记录安装脚本和待构建状态。                                                     |
| Vite 构建独立验收入口，在 Chromium 创建模块 Worker      | 三个生成库可打包并在 Worker 运行；成品通过可转移缓冲返回，Worker 随后关闭。                                            |
| Worker 生成含中文、数字、前导零编码、公式样文本的 Excel | ExcelJS 重新读取后值与类型一致，公式样文本为字符串，全部样例行可读。                                                   |
| Worker 生成中文 Word 段落和表格                         | ZIP 内存在真实段落与表格 XML，中文和关键数值正确。                                                                     |
| Worker 使用包内字体生成英文 PDF                         | 验证 pdfmake 浏览器入口、Blob 与 Worker 基础运行；PDF.js 可提取预期文本及页数。此项不替代中文字体验收。                |
| 固定中文字体与许可证已下载并通过哈希校验                | Worker 嵌入 Noto Sans SC 常规／粗体，PDF.js 提取中文及数值，逐页渲染检查。字体缺失时标记待验收，不能宣称中文兼容通过。 |
| 已安装库加入 Web 依赖后检查现有应用                     | 现有类型检查及生产构建通过；验收入口仅用于测试构建。                                                                   |

## 获准的业务场景

后续按实施清单第 7 节逐项落实测试：作者和接收人的权限、候选成员分页、并发版本冲突、回执丢失、撤回与历史结果授权；固定来源和全部 Excel 数据；Word 可编辑内容、PDF 中文分页；容量、取消、离页换号、主题与实际下载。每项业务实现前先执行对应测试并记录预期失败。

### 分享读取与导出身份

| 前提与操作                               | 验收预期                                                                                        |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 作者读取分享设置                         | 取最新定义版本，只有快照时取最新快照；读取当前成员名称与状态，失效 ID 保留为不可用。            |
| 接收人、其他用户或组织请求分享设置／候选 | 按已有报表读取授权核对，再要求作者身份；拒绝时不查询账号目录。                                  |
| 作者搜索候选并翻页                       | 仅同组织活跃账号，排除作者，ID 稳定排序；关键字特殊通配符作为普通文字，翻页结果有明确下一游标。 |
| 请求包含外加身份字段、超长搜索、非法数量 | 严格合同拒绝；默认每页 20，最多 100；已选最多 1,000。                                           |
| 身份缓存尚在，但权限已撤回               | 分享读取／保存、快照／会话导出在调用领域服务前刷新身份；刷新拒绝时不得调用业务服务。            |
| 分享读取或三类内容包响应                 | 禁止缓存，读取过程中不启动查询、执行或模型运行。                                                |

### 分享面板

| 前提与操作                       | 验收预期                                                       |
| -------------------------------- | -------------------------------------------------------------- |
| 打开作者面板，搜索并分页选择成员 | 使用最新分享基准，跨页保留已选成员；搜索旧响应不能覆盖新结果。 |
| 没有修改，或选中停用成员         | 不发保存请求；停用成员提示移除。                               |
| 保存成功或回执丢失但读取目标一致 | 重新读取实际基准及版本，刷新报表历史；不会重复 PUT。           |
| 另一页面先修改分享范围           | 保留本地增删，展示远端范围；用户确认后合并自己的增删再保存。   |
| 离页、身份变化、读取拒绝         | 中止请求并清空成员与草稿，晚到响应不能恢复内容。               |

### 导出内容与生成

| 前提与操作                             | 验收预期                                                                                                 |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 固定执行、历史快照或结束的会话导出     | 只 GET 已授权内容，核对身份与来源；下载前再次 GET，内容改变时要求重新生成。                              |
| 多个块复用来源，展示列或本地页有限制   | 按证据标识去重，Excel 含全部列及全部完整行；截断来源排除并说明。                                         |
| 数值、布尔、空值、前导零、公式样字符串 | XLSX 重新读取后值和类型准确；没有公式节点。                                                              |
| Word/PDF 导出长表及 Markdown           | 文字、标题、列表、代码、链接、表格可编辑／提取，说明摘要行数和总量；宽表分组带行号，表头重复，中文可读。 |
| 单元格或总容量越界                     | 明确报错，不能静默截断；100 表／10 万行／32 MiB 和正文 2 MiB 是本地生成上限。                            |
| 取消、离页或换号                       | 中止请求并终止 Worker，撤销下载地址；晚到结果不能下载。                                                  |
