日期：2026-10-04。用户要求从网上寻找类似界面图片，供设计审核。本轮为设计参考收集，尚未确定新的实施方案。

## 1. Metabase：顶部筛选栏

来源：[Dashboard filters 官方文档](https://www.metabase.com/docs/latest/dashboards/filters)。

![Metabase 筛选栏](https://www.metabase.com/docs/latest/dashboards/images/filters.png)

参考方向：报表详情页将日期、科室等常用条件放在顶部，控件保持紧凑，把主要空间留给图表或表格。

## 2. Linear：逐行条件编辑

来源：[Filters 官方文档](https://linear.app/docs/filters)。

![Linear 条件编辑](https://webassets.linear.app/images/ornj730p/production/158daf78ba2d520b7152a70f6758f1b39582f037-976x636.png?auto=format&dpr=2&q=95&w=1440)

## 3. Preset：筛选列表与配置分栏

来源：[Dashboard Filtering 官方文档](https://docs.preset.io/docs/dashboard-filtering)。

![Preset 筛选配置](https://cdn.document360.io/4749ddf8-aa05-4f3f-80e1-07a5d2d0f137/Images/Documentation/New_Create_Filter.png)

参考方向：左侧列出筛选项，右侧只编辑选中项，适合名称、默认值、字段关联等配置较多的情况。

## 全站风格范围讨论

用户希望基于 Linear 风格调整，并要求先讨论整体 Web 是否需要一起修改。以下是建议，待用户确认范围。

代码核对：现有 `src/styles/theme.css` 已通过 CSS 变量统一应用与 Element Plus 的颜色、字体和圆角；`app-layout.vue` 提供公共导航和页头；管理页、分析页和报表页另有各自的布局样式。因此可以统一公共视觉规则，再按模块调整信息排列与交互。

建议全站采用一致的中性色表面、文字层级、控件尺寸、间距、分隔线及状态样式。主题色用于主要操作和选中状态，亮暗模式与现有配色选择继续纳入设计。中文界面按阅读需求确定字号与行高。

| 范围 | 建议调整 |
| --- | --- |
| 公共框架 | 侧栏、页头、页面标题、按钮、菜单、弹层、表格和表单的共同规范 |
| 报表模块 | 优先细化中心卡片、详情工具栏、筛选条件行、编辑设置与 AI 侧栏 |
| 分析工作台 | 统一视觉，围绕对话阅读调整密度；沿用流式输出和完成后折叠过程的交互 |
| 管理模块 | 统一列表、筛选、表单、状态与操作区；逐页确认复杂表单布局 |
| 查询画布 | 统一节点、工具栏和属性面板的视觉；沿用画布与流光连线的交互方向 |

建议下一轮先审核三张 16:9 效果稿：报表中心、报表详情与筛选、报表编辑。三张共用同一套新侧栏和页头，并补亮暗效果对照。方向确认后，再形成文件范围、验证方式明确的实施清单。公共样式修改会影响全站，验收需覆盖各模块代表页面。

现有 Vue、Element Plus 和图标体系可用于这一视觉方向，当前建议无需新增依赖。本轮完成代码只读核对与讨论记录。
