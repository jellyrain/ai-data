## 目的和行为

API 启动只读取服务运行配置。组织管理员通过现有模型与 Agent 管理接口发布配置，业务会话按固定 Agent 和模型版本读取数据库，凭据继续加密入库。空业务库完成首建后能够先启动和登录，随后配置模型与 Agent。

部署 `analysis_runtime` 保留启停、状态与 Skill 目录、调度并发和轮询周期。模型提供方、认证、上下文容量及 Agent 单轮预算分别由数据库模型版本和 Agent 版本管理。取消部署配置自动导入默认模型、默认 Agent 的启动行为。既有数据库配置和固定版本继续使用。
