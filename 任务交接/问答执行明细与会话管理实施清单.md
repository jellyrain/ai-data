# 问答执行明细与会话管理实施清单

日期：2026-10-08

用户已回复“嗯 开始”，批准工具明细、实际 SQL 和单表导出；随后追加会话管理与报表会话分离，并明确管理以删除为主，支持多选删除。

## 实施范围

1. 工具明细：API 保存具体调用参数摘要、结果摘要与耗时，Web 按调用展示，兼容历史事件。
2. SQL：DAS 返回实际提交驱动的参数化 SQL、方言和参数类型，API 随结果证据保存；Web 支持查看和复制。参数值不另建明文副本，历史证据标记 SQL 未留存。
3. 单表导出：对话结果表增加导出入口，默认 Excel 并锁定对应证据；复用生成与下载前的权限复核及完整性检查。
4. 会话删除：单条和多选删除、按当前搜索结果全选、显示删除数量确认；只删除本人会话，运行中的会话先停止。采用现有状态字段软删除，工作台、运行详情和继续提问入口不再读取已删除会话；已保存报表继续保留。
5. 报表会话分离：依据报表执行、编辑及分析说明的持久化关联过滤工作台列表，覆盖已有记录。

- Web：工具时间线、分析依据、结果表/导出组件、会话列表/工作台状态与样式，以及单元/浏览器测试。
