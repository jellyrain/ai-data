## 配置来源与路径

API 默认读取应用的 `config/api.config.json`，可通过 `API_CONFIG_PATH` 指向其他文件。DAS 入口读取应用的 `config/das.config.json`。两个入口均使用 JSON；API 中的环境变量解析函数不是当前启动入口的默认加载方式。

API 的 `analysis_runtime.state_directory、skills_directory` 相对启动工作目录解析；JWT 默认密钥目录随应用位于 `secrets`。DAS 的 `registration_credential_path` 与 `jwt_verification_public_key_path` 相对于配置文件目录解析，DAS 主密钥保存在应用 `secrets`。

## 填写顺序

先配置 `service、metadata_sqlserver`，再配置 API 的 `jwt、bootstrap_admin、trusted_data_access_services`，随后完成 DAS 的 `api` 接入路径。模型与 Agent 使用数据库管理接口发布。发布包中的 API Skill 目录设置为 `skills`。

JSON 对象严格校验未知字段。SQL Server 池 min 必须不大于 max。`memory_tasks.lease_ms` 必须至少比 `timeout_ms` 多 5000 毫秒。SQL Server 业务源 TLS 配置按 source_id 写入 DAS `sqlserver_transports`，省略时使用加密并验证证书。

## 参考值

源码 `config/*.example.json` 面向本地开发，发布目录中的示例面向独立部署。端口 3101、3102 等示例值可以调整，并非 Schema 自动默认值。下表“默认”只列出 Schema 定义的默认值。

## apiConfigSchema {#apiconfig}

### apiConfigSchema {#apiconfig-54610707}

| 字段                           | 类型                                        | 必填 | 默认值与限制 | 说明                                                                  |
| ------------------------------ | ------------------------------------------- | ---- | ------------ | --------------------------------------------------------------------- |
| `node_env`                     | `"development"` / `"test"` / `"production"` | 是   | —            | 运行环境名称，用于日志和默认安全策略。                                |
| `memory_tasks`                 | [object](#apiconfig-8243c0cf)               | 否   | 拒绝未知字段 | 省略使用独立后台队列的默认预算。                                      |
| `service`                      | [object](#apiconfig-a21d1e4c)               | 是   | 拒绝未知字段 | API HTTP 服务配置。                                                   |
| `analysis_runtime`             | [object](#apiconfig-c0b0d7ea)               | 否   | 拒绝未知字段 | 服务级分析调度配置；模型和 Agent 的执行预算由组织配置版本提供。       |
| `metadata_sqlserver`           | [object](#apiconfig-2cc7795c)               | 是   | 拒绝未知字段 | API 自己的元数据库连接配置。                                          |
| `trusted_data_access_services` | 数组〈[object](#apiconfig-6df441b0)〉       | 否   | —            | 获准接入的 DAS 实例；省略时没有实例可注册。版本递增后旧接入凭证失效。 |
| `jwt`                          | [object](#apiconfig-29a2e689)               | 是   | 拒绝未知字段 | API 签发和校验访问 JWT 的配置。                                       |
| `bootstrap_admin`              | [object](#apiconfig-03eceddc)               | 否   | 拒绝未知字段 | 首次部署的管理员资料；省略时跳过默认账号初始化。                      |

### apiConfigSchema.memory_tasks {#apiconfig-8243c0cf}

| 字段           | 类型    | 必填 | 默认值与限制                   | 说明                                    |
| -------------- | ------- | ---- | ------------------------------ | --------------------------------------- |
| `enabled`      | boolean | 否   | 默认 `true`                    | 当前资源是否启用。                      |
| `concurrency`  | integer | 否   | ≥ 1；≤ 4；默认 `1`             | 当前 API 实例最多并行派发的分析运行数。 |
| `poll_ms`      | integer | 否   | ≥ 100；≤ 60000；默认 `2000`    | 持久队列轮询周期，单位毫秒。            |
| `timeout_ms`   | integer | 否   | ≥ 1000；≤ 60000；默认 `10000`  | 当前操作或运行的时限，单位毫秒。        |
| `lease_ms`     | integer | 否   | ≥ 5000；≤ 120000；默认 `30000` | 见本页结构及对应操作说明。              |
| `max_attempts` | integer | 否   | ≥ 1；≤ 10；默认 `3`            | 见本页结构及对应操作说明。              |

### apiConfigSchema.jwt {#apiconfig-29a2e689}

| 字段                          | 类型    | 必填 | 默认值与限制 | 说明                                                                    |
| ----------------------------- | ------- | ---- | ------------ | ----------------------------------------------------------------------- |

| `key_directory`               | string  | 否   | 最短 1       | 本地密钥目录；启动入口未收到此项时使用应用 secrets 目录。               |

### apiConfigSchema.metadata_sqlserver.options {#apiconfig-61a8995c}

| 字段                       | 类型                          | 必填 | 默认值与限制    | 说明                                                 |
| -------------------------- | ----------------------------- | ---- | --------------- | ---------------------------------------------------- |
