## 用途

把分析保存为可编辑、可再次执行的报表。API 已提供定义、参数、执行、分享和导出内容；Web 表单、画布界面及 Excel、Word、PDF 文件生成待实施。

## 创建与再次执行

1. 根据授权目录创建定义，配置标题、参数、查询和表格或图表块；也可在对话中请求保存。
2. 读取保存返回的报表 ID 和定义版本。
3. 执行时提交固定定义版本、参数和新的幂等键。
4. 查看执行状态；完成后按查询 ID 阅读各结果及其证据。
5. 修改参数再次执行，产生新的执行 ID。修改结构则先保存新的定义版本。

两处展示引用同一查询项时复用该结果。执行过程中任一查询失败或超出整次预算，整次执行失败，不交付部分完成快照。

## 二次编辑与分析说明

增加参数时同时指定它绑定的条件，保存完整定义并提交当前预期版本。对话编辑会先生成修改方案，只有该分析运行成功完成时才提交新定义。

对某次结果生成的分析说明固定在该执行上；改变参数产生新执行后，需要为新结果另行生成说明。完整操作见[报表接口](/api/reports)。

## 分享和模板

作者可将报表分享给同组织有效用户。分享修改形成新定义版本，最新名单控制历史版本访问。接收者还需具备覆盖原结果的数据权限，也可以按自己的权限执行可访问的定义。

组织模板经负责人审核发布。可复用块固定引用版本，块更新不会自动改写已保存报表。

## 导出内容

报表快照、执行结果和会话分别提供导出内容接口。读取内容包不新增业务查询；导出范围来自已保存结果。`availability: truncated` 或结果 `truncated: true` 表示该结果本身已截断。

普通明细查询最大交付 100,000 行 / 32 MiB；分析证据和整次报表执行合计最多 5,000 行 / 2 MiB。导出内容接口当前返回 JSON 内容包，文件下载能力随 Web 阶段完成。
