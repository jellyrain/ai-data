## 用途与前提

通过问题、澄清和追问完成授权数据分析，保留可复查证据。当前通过 API 接入；Web 对话页面待实施。需要有效账号、数据权限，以及已发布且启用的 Agent。

## 操作步骤

1. 按[快速上手](/guide/quickstart)登录并创建会话。会话固定所选 Agent 版本。
2. 提交问题，写明对象、时间范围和统计口径；缺少信息时助手会提出澄清。
3. 读取运行状态或订阅 [SSE](/api/events)。澄清时选择选项，或在允许时输入自定义回答，提交到同一运行。
4. 运行完成后检查答复和查询证据。展示结果可能为样本，应同时看总行数、截断与采样标记。
5. 追问继续向原会话提交新消息；后台复核历史权限，再决定沿用已有证据或重新查询。

## 确认结果

`completed` 表示本轮完成；最终消息从会话详情读取，证据由运行证据接口提供。错误或预算耗尽进入 `failed`，先查看错误码和步骤。停止分析使用取消接口。

## 常见情况

| 情况                | 操作                                                   |
| ------------------- | ------------------------------------------------------ |
| 同一问题重复提交    | 重试使用原幂等键和完全相同内容                         |
| 有待答问题          | 回答该澄清，继续原运行                                 |
| 需要换 Agent 新版本 | 创建绑定该版本的新会话                                 |
| 历史结果权限变化    | 按当前权限重新查询                                     |
| 结果仅为样本        | 读取证据与完整性标记，再决定是否缩小查询或使用明细接口 |

详细调用见[会话与消息](/api/conversations)、[分析运行](/api/analysis-runs)。
