## 用途与前提

管理同组织账号的初始角色、启停和部门范围。需要 `system_admin` 或 `user:manage`。当前通过[认证与用户接口](/api/auth)操作。

## 操作步骤

1. 首次部署在 API 配置 `bootstrap_admin` 中提供默认组织与管理员资料，启动时幂等初始化。
2. 管理员登录，读取当前身份和已有用户。
3. 创建用户时填写登录名、展示名、至少 8 字符密码，绑定当前已有的角色 ID 与例外数据范围 ID。
4. 为需要部门限制的用户保存 `department_ids`，并通过目录行策略引用该范围。
5. 按业务需要启用或停用账号；变更后重新检查实际用户访问结果。

## 确认结果

用户接口返回公开资料和 `authorization_version`。状态或部门变化递增授权版本，并清除当前实例身份缓存。空部门集合会使依赖该范围的查询被拒绝。

当前 HTTP 管理面提供用户创建、读取、启停和部门集合维护，角色与功能权限目录来自元数据配置。使用已有有效角色 ID 绑定用户，完整数据授权见[数据源与权限](/admin/data-access)。
