## 请求信息

所有操作使用 Access Token，会话仅对所属组织和用户开放。

| 方法与路径                            | 参数                                | 成功响应                          |
| ------------------------------------- | ----------------------------------- | --------------------------------- |
| POST /conversations                   | title、agent_id、agent_version 可选 | 201，Conversation                 |
| GET /conversations                    | 无                                  | 200，`{ items: Conversation[] }`  |
| GET /conversations/:id                | 会话 ID                             | 200，`{ conversation, messages }` |
| POST /conversations/:id/messages      | content、idempotency_key            | 201，`{ message, analysisRun }`   |
| GET /conversations/:id/export-content | 会话 ID                             | 200，会话导出内容包               |

## 创建与提交

```http
POST /conversations
Authorization: Bearer <ACCESS_TOKEN>
Content-Type: application/json

{"title":"九月业务分析","agent_id":"default"}
```

```json
{
  "content": "统计本月各科室就诊人次",
  "idempotency_key": "message-september-1"
}
```

`title` 为 1–512 字符；`agent_id` 为 1–128 字符；`agent_version` 为正整数且需同时指定 Agent。省略 Agent 使用 `default`，省略版本绑定创建时最新版本。`content` 去除首尾空白后为 1–64000 字符；`idempotency_key` 为 1–128 字符。

## 成功响应

Conversation 包含 `id、organizationId、userId、title、status、createdAt、updatedAt`，绑定版本时增加 `agentId、agentVersion`。`title` 可为 null，状态为 `active/archived`，日期序列化为 ISO 字符串。

消息包含 `id、conversationId、role、content、sequence、createdAt`，关联运行时有 `analysisRunId`。提交响应中的 `analysisRun` 包含 `id、conversationId、organizationId、userId、status、errorCode、errorMessage、startedAt、completedAt、createdAt`，尚未开始或没有错误的对应字段为 null。

```json
{
  "id": "conversation-001",
  "organizationId": "org-001",
  "userId": "user-001",
  "title": "九月业务分析",
  "status": "active",
  "agentId": "default",
  "agentVersion": 1,
  "createdAt": "2026-09-22T01:00:00.000Z",
  "updatedAt": "2026-09-22T01:00:00.000Z"
}
```

## 幂等与失败

消息键作用于当前会话。同键同内容复用已保存结果；同键不同内容冲突。同一会话已有活跃运行时不能并行发起新问题，澄清应使用[回答接口](/api/analysis-runs)。会话不可访问返回 `404 NOT_FOUND`，版本或状态冲突为 `409 CONFLICT`，参数不合法为 `400 INVALID_INPUT`。
