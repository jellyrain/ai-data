## 使用方式

下表按当前输入与响应 Schema 整理。对象结构通过类型链接展开，日期和跨字段行为以所属接口页为准；可省略字段的默认值不等同于接口支持任意额外参数。字段中的 Schema 名称便于客户端对照共享合同。

[memoryEventSummarySchema](#memoryeventsummary)

## memoryEventSummarySchema {#memoryeventsummary}

### memoryEventSummarySchema {#memoryeventsummary-244de3aa}

| 字段              | 类型                                                 | 必填 | 默认值与限制     | 说明                               |
| ----------------- | ---------------------------------------------------- | ---- | ---------------- | ---------------------------------- |
| `event_id`        | string                                               | 是   | 最短 1；最长 128 | 见本页结构及对应操作说明。         |
| `analysis_run_id` | string                                               | 是   | 最短 1；最长 128 | 分析运行标识。                     |
| `status`          | `"pending"` / `"processing"` / `"done"` / `"failed"` | 是   | —                | 当前资源或操作状态，合法值见类型。 |
| `attempts`        | integer                                              | 是   | ≥ 0              | 见本页结构及对应操作说明。         |
| `created_at`      | string                                               | 是   | —                | 创建时间。                         |
| `updated_at`      | string                                               | 是   | —                | 最近更新时间。                     |
| `last_error_code` | string / null                                        | 是   | —                | 见本页结构及对应操作说明。         |
