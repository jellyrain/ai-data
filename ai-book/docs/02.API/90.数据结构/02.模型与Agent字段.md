## 使用方式

下表按当前输入与响应 Schema 整理。对象结构通过类型链接展开，日期和跨字段行为以所属接口页为准；可省略字段的默认值不等同于接口支持任意额外参数。字段中的 Schema 名称便于客户端对照共享合同。

[modelConfigurationInputSchema](#modelconfigurationinput) · [modelConfigurationSchema](#modelconfiguration) · [agentDefinitionSchema](#agentdefinition) · [agentVersionSchema](#agentversion) · [skillCatalogEntrySchema](#skillcatalogentry)

## modelConfigurationInputSchema {#modelconfigurationinput}

### modelConfigurationInputSchema {#modelconfigurationinput-c7b0037d}

| 字段             | 类型               | 必填 | 默认值与限制                         | 说明                                   |
| ---------------- | ------------------ | ---- | ------------------------------------ | -------------------------------------- |
| `model_id`       | string             | 是   | 最短 1；最长 128                     | 模型稳定标识。                         |
| `version`        | integer            | 是   | &gt; 0                               | 当前资源的版本号。                     |
| `name`           | string             | 是   | 最短 1；最长 200                     | 当前资源或字段的名称。                 |
| `protocol`       | `"responses"`      | 是   | —                                    | 模型通信协议。                         |
| `base_url`       | string             | 是   | 最长 2048；uri                       | 目标服务的根 URL，具体目标见所属接口。 |
| `model`          | string             | 是   | 最短 1；最长 200                     | 提供方识别的模型名称。                 |
| `context_window` | integer            | 否   | ≥ 4096；≤ 2097152                    | 上下文容量。Agent 配置可覆盖模型配置。 |
| `api_key`        | string             | 否   | 最短 1；最长 8192；格式 `^[^\r\n]+$` | 模型提供方认证密钥。                   |
| `headers`        | 键值对象〈string〉 | 否   | —                                    | 提供方额外请求头。                     |

## modelConfigurationSchema {#modelconfiguration}

### modelConfigurationSchema {#modelconfiguration-07bfb9e4}

| 字段             | 类型           | 必填 | 默认值与限制      | 说明                                   |
| ---------------- | -------------- | ---- | ----------------- | -------------------------------------- |
| `model_id`       | string         | 是   | 最短 1；最长 128  | 模型稳定标识。                         |
| `version`        | integer        | 是   | &gt; 0            | 当前资源的版本号。                     |
| `name`           | string         | 是   | 最短 1；最长 200  | 当前资源或字段的名称。                 |
| `protocol`       | `"responses"`  | 是   | —                 | 模型通信协议。                         |
| `base_url`       | string         | 是   | 最长 2048；uri    | 目标服务的根 URL，具体目标见所属接口。 |
| `model`          | string         | 是   | 最短 1；最长 200  | 提供方识别的模型名称。                 |
| `context_window` | integer        | 否   | ≥ 4096；≤ 2097152 | 上下文容量。Agent 配置可覆盖模型配置。 |
| `enabled`        | boolean        | 是   | —                 | 当前资源是否启用。                     |
| `has_api_key`    | boolean        | 是   | —                 | 该模型版本是否配置了认证密钥。         |
| `header_names`   | 数组〈string〉 | 是   | 最多项 20         | 已配置请求头的名称列表。               |

## agentDefinitionSchema {#agentdefinition}

### agentDefinitionSchema {#agentdefinition-905419dc}

| 字段            | 类型                                | 必填 | 默认值与限制          | 说明                           |
| --------------- | ----------------------------------- | ---- | --------------------- | ------------------------------ |
| `agent_id`      | string                              | 是   | 最短 1；最长 128      | Agent 稳定标识。               |
| `version`       | integer                             | 是   | &gt; 0                | 当前资源的版本号。             |
| `name`          | string                              | 是   | 最短 1；最长 200      | 当前资源或字段的名称。         |
| `description`   | string                              | 否   | 最长 2000；默认 `""`  | 说明文字。                     |
| `instructions`  | string                              | 否   | 最长 16000；默认 `""` | Agent 执行指令。               |
| `model_id`      | string                              | 是   | 最短 1；最长 128      | 模型稳定标识。                 |
| `model_version` | integer                             | 是   | &gt; 0                | 固定模型版本。                 |
| `tool_names`    | 数组〈string〉                      | 是   | 最多项 32             | Agent 允许调用的业务工具名称。 |
| `skill_names`   | 数组〈string〉                      | 是   | 最多项 100            | Agent 绑定的 Skill 名称。      |
| `limits`        | [object](#agentdefinition-4ef4fee6) | 是   | 拒绝未知字段          | Agent 单轮执行预算。           |

### agentDefinitionSchema.limits {#agentdefinition-4ef4fee6}

| 字段                | 类型    | 必填 | 默认值与限制      | 说明                                   |
| ------------------- | ------- | ---- | ----------------- | -------------------------------------- |
| `timeout_ms`        | integer | 是   | ≥ 1000；≤ 600000  | 当前操作或运行的时限，单位毫秒。       |
| `max_tool_calls`    | integer | 是   | ≥ 1；≤ 100        | 单轮工具调用次数上限。                 |
| `max_context_bytes` | integer | 是   | ≥ 4096；≤ 1048576 | 本次业务输入的字节上限。               |
| `context_window`    | integer | 否   | ≥ 4096；≤ 2097152 | 上下文容量。Agent 配置可覆盖模型配置。 |
