## 请求信息

健康端点不需要认证，参数为空。

| 服务 | 方法与路径   | 成功响应                                           | 失败表现                                |
| ---- | ------------ | -------------------------------------------------- | --------------------------------------- |
| API  | GET /health  | 200，status: healthy                               | 表示进程可响应                          |
| API  | GET /ready   | 200，status: ready，dependencies.metadata_database | 元数据库不健康时 503，status: not_ready |
| API  | GET /version | 200，service_id、service_version                   | 按当前配置返回                          |
| DAS  | GET /health  | 200，status: healthy                               | 元数据库不健康时 503，status: unhealthy |

健康响应共有 `status、service_id、service_version、checked_at`。`checked_at` 格式为 `YYYY-MM-DD HH:mm:ss`，探针当前按服务进程时区生成，部署环境应统一时区。

```json
{
  "status": "ready",
  "service_id": "ai-bi-api",
  "service_version": "1.0.0",
  "dependencies": { "metadata_database": "healthy" },
  "checked_at": "2026-09-22 09:00:00"
}
```

API 存活不代表元数据库、业务源和模型都可用。DAS 业务源健康通过[实例诊断](/api/das)查看；模型与查询能力需实际业务请求验证。
