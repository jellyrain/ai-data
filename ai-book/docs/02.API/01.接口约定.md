## 地址与认证

本文路径直接相对于 API 根地址，例如 `http://127.0.0.1:3101`。API 没有统一的 `/api/v1` 前缀。除登录、刷新、健康检查及服务专用入口外，业务接口使用 `Authorization: Bearer <ACCESS_TOKEN>`。

JSON 请求设置 `Content-Type: application/json`；没有请求体的请求省略该头。成功响应按具体接口返回对象、`{ items: [...] }` 或空响应，接口没有统一的 `data` 包装。

## 字段与时间

多数共享业务合同使用 snake_case。登录响应和会话领域响应沿用 camelCase，具体见[认证](/api/auth)与[会话](/api/conversations)。共享合同日期为 `YYYY-MM-DD`，日期时间为东八区 `YYYY-MM-DD HH:mm:ss`；会话接口中的 Date 字段经 HTTP 序列化为 ISO 字符串。

严格对象拒绝未知字段。版本号、幂等键、列表游标的含义由各接口说明，不能把报表定义版本与结果快照版本混用。

## 错误响应

```json
{
  "code": "INVALID_INPUT",
  "message": "请求格式无效",
  "request_id": "example-request-id"
}
```

| 字段       | 类型   | 说明                                 |
| ---------- | ------ | ------------------------------------ |
| code       | string | 稳定错误码，客户端按此分支处理       |
| message    | string | 面向用户的说明                       |
| request_id | string | 当前 HTTP 请求标识，用于服务日志定位 |

| HTTP 状态 | 错误码                                                                     | 处理                                   |
| --------- | -------------------------------------------------------------------------- | -------------------------------------- |
| 400       | INVALID_INPUT                                                              | 检查字段、类型、额外参数和跨字段约束   |
| 400       | UNSUPPORTED_QUERY / QUERY_LIMIT_EXCEEDED                                   | 调整为已支持查询或缩小范围             |
| 401       | AUTHENTICATION_FAILED                                                      | 重新刷新或登录；服务凭据按对应流程处理 |
| 403       | UNAUTHORIZED / UNAUTHORIZED_OBJECT / UNAUTHORIZED_COLUMN / POLICY_REJECTED | 核对功能和数据权限                     |
| 404       | NOT_FOUND                                                                  | 检查资源存在性及当前组织、用户可见范围 |
| 409       | CONFLICT / CANCELLED                                                       | 重读版本或运行状态，勿盲目覆盖         |
| 429       | RATE_LIMITED                                                               | 降低请求频率后重试                     |
| 503       | DATA_SOURCE_UNAVAILABLE                                                    | 检查 DAS 注册与数据源健康              |
| 504       | QUERY_TIMEOUT                                                              | 检查范围和查询超时                     |
| 500       | INTERNAL_ERROR                                                             | 保留 request_id，查看服务端日志        |

## 调用链

操作教程见[快速上手](/guide/quickstart)。API 与 DAS 内部通信分别使用实例凭据、运行会话和短时服务 JWT，详见[DAS 接入](/deployment/das-registration)。客户端不能用用户 Access Token 直接替代 DAS 内部 JWT。
