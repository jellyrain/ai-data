## 目录读取

普通读取使用 Access Token；管理接口要求 `system_admin` 或 `catalog:manage`。

| 方法与路径                                                | 参数与成功响应                                                  |
| --------------------------------------------------------- | --------------------------------------------------------------- |
| GET /catalog/datasets/:sourceId                           | 200，`{ items: Dataset[] }`                                     |
| GET /catalog/datasets/:sourceId/search                    | query 必填非空，limit 默认 20、1–100；200 `{ items }`           |
| GET /catalog/datasets/:sourceId/:objectId                 | 200，当前可见 Dataset                                           |
| GET /catalog/datasets/:sourceId/:objectId/business-config | 200，业务配置；x-config-version 为当前版本                      |
| PUT /admin/catalog/datasets                               | 业务配置及可选 expected_version；204，x-config-version 为新版本 |
| GET /catalog/:sourceId/objects/:objectId/relations        | 200，一层可见关系图                                             |
| GET /admin/catalog/:sourceId/objects/:objectId/relations  | 200，管理关系图                                                 |
| POST /admin/catalog/:sourceId/relations/publish           | changes 数组；200 `{ items: 已发布关系[] }`                     |

示例读取：`GET /catalog/datasets/clinical/search?query=就诊&limit=20`。`sourceId/objectId` 来自已配置目录。普通目录输出已经过滤隐藏对象、列及不可见关系。

## 权限与版本

## 目录策略管理

目录管理接口要求 `system_admin` 或 `catalog:manage`，并校验目标角色属于当前组织。对象、字段和行条件引用按当前 DAS 目录检查。已有三个写入接口接受可选 `expected_version`，成功返回 `204`，并在 `x-policy-version` 中返回已提交版本：

- `PUT /admin/catalog/object-permissions`
- `PUT /admin/catalog/column-permissions`
- `PUT /admin/catalog/row-policies`

版本号在同一组织、同一数据源内递增。每个不可变版本保存目标角色在该源的完整策略快照、单次变更、发布人和发布时间。`expected_version` 比较目标角色当前版本，`0` 表示首次发布；不一致返回 `409 CONFLICT`。策略写入、版本快照和审计同事务提交。

| 接口                                                            | 用途                                                                    |
| --------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `GET /admin/catalog/policy-versions/:sourceId/:roleId`          | 按版本倒序读取摘要；`limit` 默认 20、最多 100，`before_version` 为游标  |
| `GET /admin/catalog/policy-versions/:sourceId/:roleId/current`  | 读取该角色当前版本及完整快照                                            |
| `GET /admin/catalog/policy-versions/:sourceId/:roleId/:version` | 读取指定历史版本                                                        |
| `POST /admin/catalog/query-preview`                             | 提交 `{ role_id, query }`，返回按该角色计算的最终 DSL 和 `output_masks` |

预览加载指定角色自身的授权资料，复用 `QueryAuthorizationService` 完成对象、字段、关联、行范围和脱敏计算。依赖具体业务用户的策略须通过该用户实际查询验收；预览返回稳定的授权拒绝原因。预览计算授权结果，业务数据执行由查询接口承担。

## 批量关系发布

## 目录关系发布

| 路径                                                       | 用途                                         |
| ---------------------------------------------------------- | -------------------------------------------- |
| `GET /catalog/:sourceId/objects/:objectId/relations`       | 当前可见对象及字段范围内的一层入向、出向关系 |
| `GET /admin/catalog/:sourceId/objects/:objectId/relations` | 管理完整关系记录，包含启停状态               |
| `POST /admin/catalog/:sourceId/relations/publish`          | `{ changes: [...] }` 原子批量发布            |

每个变更声明 `create/update/disable`。创建或更新提供 `object_id` 和 `relation`，更新及停用提供当前 `expected_version`；停用提供 `relation_id`。关系包括稳定 ID、目标对象、完整字段对、基数和批准的连接方式。字段、类型、唯一键证明、关系基数及并发版本均经校验，任意项失败则整批回滚。批量发布未列出的旧关系保留。

现有数据集配置接口读写同一批关系记录，读取响应的 `x-config-version` 用于完整配置保存的 `expected_version`。完整配置保存按提交列表替换该对象的关系；入向关系仅供图浏览，不产生隐式反向执行权。

## 错误与字段

未知对象、字段或资源不可访问会被拒绝；旧预期版本为 `409 CONFLICT`，无管理权限为 `403 UNAUTHORIZED`，输入及目录约束无效为 `400 INVALID_INPUT`。完整对象、列、行策略与关系字段见下方参考，配置流程见[数据源与权限](/admin/data-access)。
