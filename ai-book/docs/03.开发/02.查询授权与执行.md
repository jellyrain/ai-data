## 模块职责

API 的 `src/query/`、`src/catalog/` 计算可执行 DSL 与权限；DAS 的连接器、查询编译和 `query-execution/` 负责只读执行、取消、脱敏及审计。共享结构位于 `packages/contracts/src/query/`。

## 调用流程

```text
客户端 DSL
  → API 当前身份、对象、字段、关系和行策略检查
  → 构造 access + query + signature，签发短时 JWT
  → DAS 验签、有效期、对象白名单和编译能力检查
  → 驱动执行参数化只读请求
  → DAS 脱敏与审计
  → API 再次检查权限，交付结构化结果
```

权限条件按主对象、连接对象及连接语义放置，外连接可选侧预过滤保留主记录。参数化数据集使用受控参数表达行范围；缺少可执行授权参数时拒绝请求。客户端参数不能覆盖服务端权限。

## 查询与结果

[查询 API](/api/query)记录请求和结果合同。[关系聚合](/develop/relational-aggregation)说明粒度、去重及预聚合，[参数化数据集](/develop/parameterized-queries)说明存储过程和 HTTP 映射。

普通查询最多交付 100,000 行 / 32 MiB；分析证据和报表有独立预算。`truncated` 及 `delivery` 表达结果完整性，前端应随结果展示。

## 扩展与验证

增加查询能力时同步扩展共享 Schema、API 授权生成、DAS 编译执行，再通过对应场景开放。使用已存在的合同、编译器和集成测试覆盖权限、参数化、取消与结果上限。文档更新由用户明确发起。
