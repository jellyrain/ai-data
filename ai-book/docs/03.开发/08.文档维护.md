## 更新时机

只有用户明确要求更新文档时，才按获准范围修改 ai-book，包括说明、归档、首页和站点配置。日常开发、功能新增、接口调整和修复不自动触发这里的更新。

## 编写流程

```text
用户明确要求 → 提交范围清单 → 用户批准
  → 核对当前实现和验证记录 → 更新说明与相关归档
  → 检查链接和构建 → 页面预览 → 保存交付说明
```

完整规范为仓库 `ai-book/AGENTS.md`。需求设计保存在 `需求文档/`，实施清单和验证经过保存在 `任务交接/`。

## 页面约定

页面采用编号中文文件名；Frontmatter 包含 `title`、`date`、`permalink`、`categories` 和 `tags`。正文从二级标题开始。普通内容修订保留创建日期。永久链接使用英文小写与连字符，站内链接优先引用永久地址。

每个主题维护一份主要说明，通过链接连接接口、操作和开发内容。API 参数以当前 Schema 为准，命令写明执行目录，认证使用占位值或交互输入。Web 操作说明以实际页面为依据。

## 验证

使用已有格式工具、链接检查和 `pnpm docs:build`。README 原有内容保留，追加必要入口。已完成交付写入 `任务交接/`，归档按实际日期或正式版本记录。
