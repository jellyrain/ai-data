## 完成目标

完成 API 与 DAS 启动、模型和 Agent 发布后，通过接口提交一个问题并查看运行结果。操作机需要 PowerShell，示例 API 地址为 `http://127.0.0.1:3101`。

## 1. 准备服务与权限

按[首次启动](/deployment/first-start)运行 API，按[DAS 接入](/deployment/das-registration)注册 DAS。随后完成[数据源与目录权限](/admin/data-access)配置，并按[模型与 Agent](/admin/models-agents)发布模型及 `default` Agent。自动分析需要 `analysis_runtime.enabled: true`。

管理员的功能管理权限不替代数据查询权限，应使用已授予对象、列和行范围的账号验证分析。

## 2. 登录

```powershell
$apiBase = 'http://127.0.0.1:3101'
$credential = Get-Credential -Message '输入 API 账号和密码'
$body = @{
  username = $credential.UserName
  password = $credential.GetNetworkCredential().Password
} | ConvertTo-Json
$login = Invoke-RestMethod "$apiBase/auth/login" -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
$headers = @{ Authorization = "Bearer $($login.accessToken)" }
```

## 3. 创建会话并提交问题

```powershell
$conversation = Invoke-RestMethod "$apiBase/conversations" -Method Post -Headers $headers -ContentType 'application/json; charset=utf-8' -Body '{"title":"九月业务分析","agent_id":"default"}'
$messageBody = @{
  content = '请按科室统计本月就诊人次，先核对可用指标和日期口径。'
  idempotency_key = [guid]::NewGuid().ToString()
} | ConvertTo-Json
$submitted = Invoke-RestMethod "$apiBase/conversations/$($conversation.id)/messages" -Method Post -Headers $headers -ContentType 'application/json; charset=utf-8' -Body $messageBody
$runId = $submitted.analysisRun.id
Invoke-RestMethod "$apiBase/analysis-runs/$runId" -Headers $headers
```

问题中的业务对象应替换为实际授权目录。消息提交返回 `201`，只表示消息和运行已创建；随后读取运行状态。

## 4. 确认结果

`waiting_clarification` 表示需要按[澄清接口](/api/analysis-runs)回答；`completed` 表示本次运行完成。通过 `GET /conversations/:id` 读取最终消息，通过 `GET /analysis-runs/:id/evidence` 读取证据。流式客户端按 [SSE](/api/events)接入。

若返回 Agent 不存在，先检查本组织发布的 Agent 标识；若运行长期停在 `created`，核对自动调度配置与服务日志。
