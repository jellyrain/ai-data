## 数据与权限

`source_id` 标识 DAS 上绑定一个目标库的数据源。`object_id` 标识表、视图、已配置存储过程或虚拟数据集。API 业务目录补充名称、统计粒度、唯一键、字段策略和批准关系。功能权限决定能否管理系统，数据权限决定能查询哪些对象、字段和行。

## 模型、Agent 与 Skill

模型版本固定 Responses 地址、模型名和认证。Agent 版本固定模型版本、指令、工具白名单、Skill 快照与执行预算。会话创建时绑定 Agent 版本，后续发布新版本供新会话选择。Skill 保存分析方法与查询规则，完整目录在 Agent 发布时形成固定快照。

## 会话、运行与证据

会话包含多轮消息。每次提交用户消息创建分析运行；同一会话串行执行，澄清继续原运行，追问创建新运行。证据保存实际查询、授权上下文和有完整性标记的结果，用于结论复核、报告与后续追问。

## 指标、报表与知识

指标固定统计粒度、时间依据和总计规则，经审核发布后执行。报表定义保存参数、查询与展示结构；每次执行保存实际参数和结果，历史快照另有版本。组织模板通过知识审核发布。个人偏好按组织和账号保存，一般偏好直接应用；冲突或恢复停用的自动应用需要确认。
