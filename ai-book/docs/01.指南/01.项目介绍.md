## 用途

AI BI 将自然语言问题转换为受权限约束的数据分析，保存查询证据，并将分析沉淀为可重复执行的报表。当前项目名称为 ai-data，说明站点为 ai-book。

## 服务职责

| 组件 | 负责的工作                                                               | 当前状态   |
| ---- | ------------------------------------------------------------------------ | ---------- |
| API  | 登录、组织权限、业务目录、模型与 Agent、分析运行、指标、报表、知识与记忆 | 已实现后端 |
| DAS  | 连接业务数据源、读取对象目录、编译参数化只读查询、脱敏和审计             | 已实现后端 |
| Web  | 对话、参数表单、报表详情、画布及文件下载界面                             | 待实施     |

## 从问题到结果

```text
用户问题 → API 校验身份 → Agent 核对口径与目录
                            ↓
                      API 生成授权 DSL
                            ↓
                DAS 验签、编译、只读查询与脱敏
                            ↓
                   API 保存证据、答复与报表
```

模型通过业务工具调用 API。业务数据库连接由 DAS 管理；对象、字段、行范围和已批准关系由 API 在每次查询时计算。报表分享和历史结果读取也重新检查访问权限。
