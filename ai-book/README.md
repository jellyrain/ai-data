## 文档维护

本目录维护 API、DAS 和 Web 的说明文档，站点源文件位于 `docs/`。新增或更新说明前，先阅读[说明文档编写规范](AGENTS.md)。上述启动、打包命令在 `ai-book` 目录执行。

文档分为七类，沿用现有目录编号：

| 分类     | 目录                | 内容                                          |
| -------- | ------------------- | --------------------------------------------- |
| 指南     | `docs/01.指南/`     | 产品介绍、职责、概念与快速上手                |
| API 参考 | `docs/02.API/`      | 请求、响应、错误码、SSE 与调用示例            |
| 开发指南 | `docs/03.开发/`     | 工程结构、实现约定、测试与扩展                |
| 部署运维 | `docs/04.部署运维/` | 打包、配置、启动、接入、升级与故障排查        |
| 使用手册 | `docs/05.使用手册/` | 对话、报表、参数、画布、分享与导出            |
| 管理手册 | `docs/06.管理手册/` | 用户权限、数据源、模型、Agent、知识审核与任务 |
| 归档记录 | `docs/07.归档记录/` | 按日期或版本记录新增、修复、调整与升级事项    |

新增分类随对应内容建立目录和站点导航；具体命名、Frontmatter、页面模板及验证方式以编写规范为准。

## 更新时机

只有用户明确要求更新文档时，才按获准范围修改 `ai-book` 的说明、归档、首页和站点配置。日常开发、功能新增、接口调整和问题修复不自动触发本目录更新，需要集中整理时由用户明确发起。

## 阅读入口

当前说明按 API 和 DAS 的已实现能力编写，Web 的接入范围见[当前完成状态](docs/01.指南/04.当前完成状态.md)。首次阅读可从[项目介绍](docs/01.指南/01.项目介绍.md)和[快速上手](docs/01.指南/02.快速上手.md)开始。

部署人员阅读[首次配置与启动](docs/04.部署运维/02.首次配置与启动.md)和[DAS 接入](docs/04.部署运维/03.DAS接入.md)；接口调用方阅读[接口约定](docs/02.API/01.接口约定.md)；历史更新见[更新索引](docs/07.归档记录/01.更新索引.md)。
